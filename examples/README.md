# 示例曲目 / Example scores

用主界面的“导入”打开对应 MusicXML；曲目名称为 **Day One** 和 **Are You Lost**。它们是独立下载的学习示例，不会自动加入已有曲库。

## Day One

- 作曲：Hans Zimmer。
- 钢琴改编与参考演奏：BiBiPiano。
- 原谱整理：lemondemelan。
- [参考演奏](https://www.bilibili.com/video/BV1vi4y1K7oA/)；[原谱页面](https://www.bilibili.com/opus/569301329585547900)。
- 119 小节，包含变拍、分手、速度、力度及延音踏板。播放用的踏板和力度经过编辑，不是原演奏动作的精确记录。

## Are You Lost

- 作曲：park bird。
- 此学习整理以 Cuppix 的钢琴版本为参考；[参考视频与谱面来源](https://www.bilibili.com/video/BV11p4y1F79w/)。
- 音符、节奏、速度及踏板用于本软件的钢琴练习播放；并非出版社认证原版谱。
